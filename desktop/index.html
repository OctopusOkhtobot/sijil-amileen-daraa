المستخدمون — صلاحية المصمم

حساب asma فقط يدير المستخدمين ويرى كل السجلات. أي مستخدم آخر يتعامل مع البيانات التي أدخلها من حسابه. تعديل نص البرنامج يبقى في المستودع.

ربط السجل مع Supabase

  1. افتح مشروعك في Supabase → SQL Editor → الصق الأمر ثم Run.
  2. من الشريط الأيسر: Project Settings → API Keys. انسخ Publishable key (يبدأ بـ sb_publishable_). إذا ما ظهر، افتح تبويب Legacy API keys وانسخ anon.
  3. هذا الزر للمصمم فقط. بعد الحفظ تُربط القاعدة بكل الحسابات، والمستخدم العادي لا يرى هذا الزر.
