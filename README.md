# السجل العام للعاملين في الدولة

تطبيق ويب عربي لإدارة **البطاقات الذاتية وسجل الموظفين والتقارير الإحصائية**، موجّه للاستخدام في مديرية الشؤون الاجتماعية والعمل بدرعا. يعمل بواجهة عربية من اليمين إلى اليسار، ويمكن فتحه من المتصفح.

[![فتح التطبيق](octopus.jpg)](https://olive-agent.netlify.app/)

**رابط التطبيق:** [olive-agent.netlify.app](https://olive-agent.netlify.app/) · **المستودع:** [OctopusOkhtobot/sijil-amileen-daraa](https://github.com/OctopusOkhtobot/sijil-amileen-daraa)

> الصورة أعلاه شعار موجود ضمن ملفات المشروع، ويمكن الضغط عليها لفتح التطبيق. لا يحتوي المستودع حالياً على لقطات شاشة فعلية لواجهات البرنامج.

## ماذا يقدم البرنامج؟

- **البطاقة الذاتية:** إدخال بيانات العامل على صفحتين، تشملان البيانات الشخصية والوظيفية، والتبدلات الوظيفية والإجازات والمكافآت والعقوبات وغيرها.
- **سجل الموظفين:** إنشاء سجلات العاملين وتعديلها والبحث فيها، مع ربط السجل ببطاقته الذاتية عند تطابق البيانات.
- **التقارير والإحصاء:** تصفية السجلات، اختيار أعمدة التقرير، عرض إحصاءات، ثم الطباعة أو التصدير إلى Excel.
- **استيراد وتصدير:** استيراد ملفات Excel أو نسخة JSON، وتصدير البطاقات أو السجلات والتقارير إلى Excel، مع إمكانية طباعة البطاقة.
- **التحقق من الرقم الوطني:** يمنع الحفظ عند غياب الرقم الوطني لشخص له اسم، أو عند وجود أحرف أو رموز فيه، وينبّه عند اكتشاف رقم مكرر.
- **حسابات المستخدمين:** يوفّر واجهة دخول وتسجيل، مع واجهة إدارة للمستخدمين تظهر لحساب المصمم.
- **العمل محلياً أو اختيارياً مع السحابة:** تُحفظ البيانات محلياً في المتصفح، ويمكن تهيئة مزامنة اختيارية مع Supabase من زر **الربط السحابي**.
- **واجهة قابلة للتثبيت:** يتضمن المشروع ملف Web App Manifest وعاملاً للخدمة لدعم التثبيت والعمل كتطبيق ويب تقدمي في المتصفحات المدعومة.

## الاستخدام

1. افتح [التطبيق](https://olive-agent.netlify.app/) من متصفح حديث.
2. سجّل الدخول أو أنشئ حساب مدخل بيانات من شاشة الدخول.
3. من تبويب **البطاقة الذاتية** أنشئ بطاقة، وأدخل البيانات المطلوبة، ثم اضغط **حفظ**. يلزم إدخال رقم وطني رقمي صالح قبل حفظ بطاقة باسم.
4. استخدم تبويب **سجل الموظفين** لإضافة سجل أو البحث والتصفية وتعديله. يمكنك فتح البطاقة الذاتية المرتبطة به.
5. استخدم تبويب **التقارير والإحصاء** لاختيار الحقول والتصفية والطباعة أو تصدير كشف Excel.
6. أنشئ نسخة احتياطية بصيغة JSON بشكل دوري، واحفظها في مكان آمن. الاستيراد والتصدير متاحان من شريط أدوات البطاقة.

## تشغيل نسخة من المستودع

### محلياً

يتكوّن التطبيق أساساً من HTML وCSS وJavaScript، وتوجد دالة Netlify اختيارية للمزامنة السحابية. يمكن تقديم ملفات المشروع محلياً بخادم ويب بسيط، مثلاً:

```bash
git clone https://github.com/OctopusOkhtobot/sijil-amileen-daraa.git
cd sijil-amileen-daraa
python3 -m http.server 8000
```

ثم افتح [http://localhost:8000](http://localhost:8000). يتضمن المشروع `package.json` للاعتماد على `@netlify/blobs` في وظيفة Netlify؛ تشغيل الواجهة محلياً لا يهيّئ تلقائياً وظيفة Netlify أو اتصال Supabase.

### النشر على Netlify

اربط المستودع بموقع Netlify وانشره بإعدادات البناء الموجودة في [`netlify.toml`](netlify.toml). إعداد المشروع يحدد جذر المستودع للنشر ومجلد `netlify/functions` للدوال. رابط النسخة المنشورة المشار إليه في هذا الدليل هو [olive-agent.netlify.app](https://olive-agent.netlify.app/).

## البيانات والخصوصية — اقرأ قبل إدخال بيانات حقيقية

هذا التطبيق يتعامل مع بيانات شخصية وموظفين. **لا تعتبر شاشة الدخول أو إخفاء الأزرار ضماناً أمنياً كافياً لحماية السجلات.** في النسخة الحالية تُخزَّن بعض البيانات محلياً في `localStorage`، كما أن كود الدخول يتضمن إعداداً ثابتاً لحساب المصمم. يلزم مراجعة آلية المصادقة والصلاحيات على الخادم قبل الاعتماد على التطبيق لحماية بيانات فعلية.

المزامنة مع Supabase اختيارية. ملف [`setup.sql`](setup.sql) الحالي ينشئ سياسات قراءة وكتابة واسعة لأدوار `anon` و`authenticated`؛ تشغيله كما هو قد يتيح الوصول إلى بيانات الجدول على نطاق أوسع مما ينبغي. **لا تشغّله على قاعدة تحوي بيانات شخصية أو حساسة قبل تعديل سياسات RLS واختبارها**، ولا تضع مفاتيح سرية أو كلمات مرور في ملفات عامة أو تشاركها. استخدم مفتاحاً عاماً مخصصاً (Publishable/anon) فقط بعد إعداد سياسات قاعدة البيانات المناسبة، وراجع إعدادات Netlify/Supabase مع مسؤول تقني.

- البيانات المحفوظة محلياً مرتبطة بالمتصفح والجهاز؛ حذف بيانات الموقع أو تغيير الجهاز قد يؤدي إلى فقدانها.
- النسخة الاحتياطية JSON قد تحتوي بيانات شخصية؛ خزّنها وشاركها بحذر.
- قبل النشر أو الاستخدام الرسمي، راجع صلاحيات المستخدمين، سياسات قاعدة البيانات، والالتزامات المحلية المتعلقة بالخصوصية وحفظ السجلات.

## ملفات مهمة

- [`index.html`](index.html): واجهة التطبيق.
- [`app.js`](app.js): البطاقات الذاتية والحفظ والاستيراد والتصدير.
- [`hr.js`](hr.js): سجل الموظفين والبحث والتقارير.
- [`excel-import.js`](excel-import.js) و[`excel-export.js`](excel-export.js): وظائف Excel.
- [`auth.js`](auth.js): الدخول وإدارة المستخدمين في الواجهة.
- [`cloud-sync.js`](cloud-sync.js): تكامل المزامنة مع Supabase.
- [`netlify/functions/sb.js`](netlify/functions/sb.js): دالة Netlify الوسيطة.
- [`setup.sql`](setup.sql): مثال إعداد قاعدة البيانات وسياساتها؛ راجع تحذير الخصوصية أعلاه قبل تشغيله.
